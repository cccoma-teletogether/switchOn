# 기획 문서

## 1. 제품 정의

### 제품명

스위치온 다이어트 매니저

### 문제 정의

주차형 식단 프로그램을 진행하는 사용자는 체중 하나만으로 진행 여부를 판단하기 어렵습니다. 체지방, 근육량, 측정 변동, 컨디션, 운동 수행력, 단백질 섭취를 함께 기록하고 다음 주차 행동으로 연결할 수 있는 간단한 도구가 필요합니다.

### 제품 목표

사용자가 매일 측정과 컨디션을 기록하고, 한 주의 변화를 이해한 뒤, 다음 주차 진행 또는 현재 주차 반복을 스스로 결정하도록 돕습니다.

### 비목표

- 질병 진단, 치료, 의학적 식단 처방
- 전문 의료기기 수준의 체성분 분석
- 코치·의료진을 대신한 자동 의사결정
- 서버 기반 커뮤니티나 결제 기능

## 2. 대상 사용자

1. 주차형 다이어트 프로그램을 혼자 진행하며 기록이 필요한 사람
2. 체중뿐 아니라 체지방·근육량 추세를 보고 싶은 사람
3. 측정값과 생활 상태를 함께 보며 다음 주차를 결정하고 싶은 사람

사용자는 복잡한 설정이나 전문 용어보다 “오늘 무엇을 기록하고, 다음에 무엇을 하면 되는지”를 빠르게 이해해야 합니다.

## 3. 핵심 사용자 흐름

```text
시작일 설정
  → 날짜별 체성분·컨디션 기록
  → 캘린더와 그래프로 변화 확인
  → 운동·피로·단백질 자기점검
  → 다음 주차 판정 확인
  → 현재 주차 반복 또는 다음 주차 진행
  → JSON으로 개인 데이터 백업
```

## 4. 기능 요구사항

### P0 — 현재 핵심 기능

| 기능 | 사용자 가치 | 완료 기준 |
|---|---|---|
| 시작일 설정 | 주차 계산 기준을 개인 일정에 맞춤 | 시작일 변경 후 주차·기간·기록 구간이 갱신됨 |
| 날짜별 기록 | 체중·근육량·체지방을 축적 | 같은 날짜 기록은 수정되고 다른 날짜 기록은 보존됨 |
| 캘린더 | 기록일과 단식일을 한눈에 확인 | 측정일·단식일·선택일이 구분되어 표시됨 |
| 체성분 그래프 | 수치 변화와 방향을 확인 | 3개 지표와 3개 비교 범위를 선택 가능 |
| 다음 주차 판정 | 기록을 행동으로 연결 | 측정 추세와 자기점검을 함께 반영한 상태를 표시 |
| 주차별 식단 가이드 | 현재 단계의 원칙 확인 | 1~4주차 식단, 단식, 허용 식품을 열람 가능 |
| 백업·복원 | 브라우저 데이터 손실에 대비 | JSON 저장 및 유효 파일 복원이 가능 |

### P1 — 다음 개선

- 측정 조건(시간, 공복, 운동 여부) 기록
- 기록 수정·삭제 이력 또는 되돌리기
- 단식 일정 반복 설정과 알림
- 판정 결과의 근거를 펼쳐 보는 상세 계산값
- 비정상 입력값, 누락된 자기점검, 측정 간격에 대한 안내

### P2 — 확장 후보

- 계정 기반 동기화
- 코치 공유용 읽기 전용 리포트
- 주간 회고 및 메모 검색
- 건강 상태·복용약을 고려한 안전 안내 강화

## 5. 판정 및 안전 원칙

- 체중 단일 지표로 진행 여부를 결정하지 않습니다.
- 체지방 방향, 근육량 방향, 최근 추세, 컨디션을 함께 봅니다.
- 짧은 기간의 측정 변동을 전체 추세와 구분합니다.
- 운동 수행력 저하, 심한 피로, 단백질 부족은 주의 신호로 취급합니다.
- 자동 판정은 참고 정보이며 사용자가 최종 행동을 선택합니다.
- 건강 상태, 복용 약, 섭식장애 이력, 임신·수유 등 특수 상황에서는 단식이나 식단 변경 전 의료진 상담을 안내합니다.
- 앱 문구는 “권장”·“검토” 중심으로 작성하고 확정적 의료 표현을 피합니다.

## 6. 콘텐츠 원칙

- 주차별 식단·단식 정보는 동일한 형식으로 제공해 비교가 쉽도록 합니다.
- 참고 이미지와 텍스트 설명이 다르면 출처와 차이를 명시합니다.
- 허용 식품과 금지 식품을 절대적 의학 기준처럼 표현하지 않습니다.
- 측정 오차와 측정 조건의 영향을 설명합니다.
- 사용자가 다음 행동을 바로 알 수 있도록 가이드 마지막에 진행 기준을 둡니다.

## 7. 성공 지표

초기에는 개인 데이터 보호를 위해 서버 분석 없이, 사용성 확인을 위한 수동 지표부터 운영합니다.

- 기록 완료율: 프로그램 사용자 중 7일 내 1회 이상 기록한 비율
- 주간 기록 지속률: 2주차 이후에도 기록을 남긴 비율
- 판정 행동 완료율: 판정 확인 후 반복 또는 다음 주차 진행을 선택한 비율
- 백업 성공률: 저장하기 후 유효 JSON 파일이 생성되는 비율
- 오류율: 기록 저장·복원·모바일 화면에서 발생한 사용자 제보 건수
- 이해도: 사용자가 그래프와 판정 근거를 이해했다고 응답한 비율

건강 관련 결과를 성공 지표로 삼지 않고, 기록·이해·안전한 사용을 우선 측정합니다.

## 8. 릴리스 우선순위

### 현재 릴리스

정적 개인용 MVP. 기록, 시각화, 주차 가이드, 판정 보조, 백업·복원을 제공하며 서버 계정은 사용하지 않습니다.

### 다음 릴리스 기준

다음 항목을 충족하면 P1 개선을 우선 검토합니다.

1. 기록 저장과 JSON 복원에 대한 회귀 테스트가 있음
2. 잘못된 입력과 빈 데이터 상태가 명확함
3. 판정 근거가 사용자에게 충분히 설명됨
4. 모바일 접근성과 키보드 사용성 문제가 해결됨
5. 건강·단식 관련 안전 문구가 모든 주요 진입점에 노출됨

## 9. 오픈 질문

- 체성분 기록의 기준 측정값을 사용자가 직접 설정할지, 첫 주 기록을 자동 기준으로 삼을지
- 주차 종료 시점에 자동 알림을 제공할지
- 컨디션·운동·단백질 기록을 현재처럼 3개 선택지로 둘지, 일별 기록으로 확장할지
- 서버 동기화를 도입할 경우 건강정보의 보존 기간·삭제·암호화 정책을 어떻게 정할지
